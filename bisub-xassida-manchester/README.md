# Bisub Xassida — Manchester, UK 2026 (3e Édition)

Page web permettant aux participants d'insérer leur photo dans le cadre officiel
de l'événement et de la télécharger en PNG.

24 Décembre 2026 — 39 Varley St, Milles Platting, Manchester M40 8EE

## Déploiement Railway

1. Pousser ce dossier sur un **nouveau** dépôt GitHub
2. Railway → New Project → Deploy from GitHub repo
3. Settings → Networking → Generate Domain

Tout est embarqué dans `index.html` (template, fond, logo en base64).
Aucune base de données ni variable d'environnement.
